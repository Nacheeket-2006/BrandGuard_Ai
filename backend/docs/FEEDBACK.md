# Structured user feedback protocol

Status: protocol supplied; **no external participant sessions have been conducted or fabricated**. Automated tests and the agent's browser walkthrough are engineering verification, not user research.

Recruit one content creator, one brand manager, and one administrator. Use synthetic content. Ask participants to complete the tasks unaided, record consent before any recording, and collect no unnecessary personal data.

| Persona | Task | Success measure |
| --- | --- | --- |
| Creator | Audit the sample and explain one flagged claim | Correctly identifies cited source and consequence |
| Creator | Accept one suggestion, reject another, then reconsider | Understands that rejection does not remove risk |
| Admin | Upload a structured source and deactivate it | Can distinguish active sources and offline rule coverage |
| Manager | Compare revisions and approve a clean submission | Finds diff, evidence, and exact revision sign-off |
| Manager | Return a draft with rejected findings | Understands why unresolved risk blocks approval |

Record completion, time, errors, assistance needed, confusion, trust in citations, and expected behavior. Ask 1–5 ratings for ease of use, feedback clarity, and confidence in final approval, followed by “What would you change first?” Do not treat a 100 score as a guarantee of legal compliance.
